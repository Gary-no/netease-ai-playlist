# 前端视觉改版：itsoffbrand 风格 + 全局暗色主题

## 变更概要

### 依赖变更
- 新增 `tailwindcss@4.3.3` + `@tailwindcss/vite`：CSS 工具类（仅 theme/utilities，无 preflight 重置）
- 新增 `gsap@3.15.0`：滚动触发动画（ScrollTrigger 插件）
- 新增 `three@0.185.1`：全屏粒子波背景（异步动态导入，拆为独立 chunk）
- 新增 `@fontsource-variable/space-grotesk` + `@fontsource-variable/inter`：自托管可变字体（离线可用）

### 配置文件
- `vite.config.js`：注入 `@tailwindcss/vite` 插件

### 设计令牌（style.css → 全局重写）
- **暗色为默认**（itsoffbrand 风格）：`--bg: #060608`，`--text: #f5f5f7`
- 新增变量：`--font-display`（Space Grotesk 标题字体）、`--modal-overlay`、`--success`、`--text-on-accent`、`--accent-shadow`、`--accent-shadow-strong`
- 保持 `[data-theme='light']` 完整兼容（亮色可切换）
- 保留 doodle 波形 SVG 背景 / glass 类 / spring 动画

### 新增组件
- **`ParticleField.vue`**：Three.js 全屏点阵正弦波背景，鼠标视差跟随，主题切换自动变色，隐藏标签页时暂停渲染

### 重写组件
- **`HomeView.vue`**（itsoffbrand 风格情感入口）
  - HERO 全屏：超大 `clamp(44px, 8.5vw, 104px)` 标题、渐变亮色词、滚动 cue
  - 四卡片出入口布局（4列→2列→1列响应式），悬停 3D 倾斜（GSAP）
  - 滚动触发浮现动画（GSAP ScrollTrigger）
  - Before/After 对比 + 三步用法 + 页脚信任信息
- **`App.vue`**：品牌标题字体改用 `--font-display`

### 颜色变量化（修复 19 处硬编码）
- `LoginModal.vue`：遮罩层 rgba → `--modal-overlay`、success 绿 → `--success`、#fff → `--text-on-accent`
- `ClassifyFlow.vue`：chip/slider/action/done 中的 14 处硬编码全替换为 CSS 变量
- `ChatPanel.vue` / `PlaylistPanel.vue`：零硬编码，自动适配
